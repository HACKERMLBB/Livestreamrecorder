## 💡✨ TIPS AND TRICKS ✨💡

> 💖 TIP 1 - Why 45MB?
> Telegram limit is 50MB!!! 45MB is safe!!! 💪
> So every part sends as VIDEO!!! 🎥 Not document!!! 🎉

> 💖 TIP 2 - Why 360p?
> Small file = Fast upload!!! ⚡
> Fast upload = Less waiting!!! ⏳➡️✨
> Perfect for phone!!! 📱💕

> 💖 TIP 3 - Add Link Without Bot?
> Open code, find LINKS = [], add your link there!!! 📝✨

> 💖 TIP 4 - Keep Bot Awake?
> Use UptimeRobot to ping your Render link every 5 minutes!!! 🏓✨

> 💖 TIP 5 - Want Better Quality?
> Change 360 to 480 or 720 in code!!! 🎞️
> But file will get bigger!!! 💾

> 💖 TIP 6 - Want Smaller Parts?
> Change -fs 45M to -fs 30M!!! ✂️
> You will get more parts but smaller!!! 🧩

## 🆘✨ TROUBLESHOOTING ✨🆘

| 😢 Problem | 🥺 Why? | 💖 Solution |
| --- | --- | --- |
| Bot not recording? | Link is offline | Check with /live!!! 🔍 |
| Bot says m3u8 not found? | Live not started yet | Wait a little!!! ⏳💕 |
| No audio? | Old version | Update to new code!!! New code fixes it!!! 🎵✨ |
| File goes as document? | File too big | This version is 45MB, should be video!!! If still, restart bot!!! 🔄 |
| MixDrop failed? | Wrong key / email | Check your secrets!!! 🔐 |
| Bot offline on Render? | Render slept | Ping it with UptimeRobot!!! 🏓 |
| FFmpeg not found? | FFmpeg not installed | Install FFmpeg!!! See installation!!! 🛠️ |
| Telegram says file too large? | Very rare | It means part > 50MB, restart and check -fs 45M!!! 📦 |

Still stuck? Don't cry!!! 🥺💕
Check logs on Render!!! Logs tell you everything!!! 📜✨
